# Seguridad

## Información que nunca debe subirse

No confirmar en Git ni adjuntar a Issues o Pull Requests:

- tokens de acceso;
- claves de servicio de Google Cloud;
- archivos de credenciales;
- contraseñas;
- `.env` real;
- GeoTIFF o datos privados no autorizados.

## Reporte de una vulnerabilidad

Si se detecta una exposición de credenciales, revocar primero la credencial afectada y comunicar el incidente directamente al responsable técnico del repositorio. No publicar secretos en un Issue abierto.
